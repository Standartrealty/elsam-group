# Проверка и ограничения

## Первоисточник

- Официальный сайт: https://elsamgroup.ru/.
- 23 попытки загрузки страниц; сохранено 19. Четыре некорректные URL на политику/оператора отмечены в каталоге, действительные страницы сохранены.
- 478 записей ресурсов; сохранено 467. Ошибки и внешние ссылки доступны в `source-content/catalog.json`.
- Пять строящихся проектов: Династия, Весна, Москва, Семья, Рассвет. Два поимённо представленных завершённых объекта: Айсберг и торговый центр.
- 61 планировка взята с соответствующих проектных страниц; сохранены изображение, подпись и URL источника. Это не актуальная база доступных квартир.
- Ссылки на документы Яндекс сохранены; PDF не скачаны.

## Расхождения исходника

- Главная говорит о трёх/четырёх проектах, фактически содержит пять карточек. Новая версия показывает пять.
- Для «Семьи» и «Рассвета» расходятся города в карточках и описаниях. В списке указан регион «Дагестан»; адреса сохранены как в карточках. Уточнить у компании перед коммерческим запуском.
- У «Весны» встречаются разные обозначения класса. Главные карточки не обещают класс.
- Офис на странице контактов: Ленина, 14. В 2ГИС: Ленина, 16. В новой версии используется официальный адрес 14.
- В шапке исходника каждый день 9–19, в контактах будни 9–19, выходные 10–17. Используется расписание страницы контактов.
- Подписи некоторых планировок отличаются от названий файлов/дублирующих подписей: Династия 103,43/103,42 и 131,85/131,81; Москва 2-к 93,54 с именем изображения 3_93-54; Семья 46,4/46,6. В каталоге воспроизведены карточки основного блока, точные параметры требуют подтверждения компании.
- Цифра 9 объектов используется по данным компании; только два завершённых объекта доступны поимённо.

## Техническая проверка

Проверены загрузка пяти проектов, открытие проекта и документов, галерея, фильтрация планировок по комплексу и комнатам, увеличение, мобильные контакты, демонстрационная заявка с успешным состоянием. На ширине 390px горизонтального переполнения нет. Проверка синтаксиса и статическая сборка проходят. В консоли локальной страницы ошибок не обнаружено.

## Публикация

Отдельные GitHub и Vercel проекты `elsam-group`. Защита Vercel Authentication сохранена согласно ранее выбранному пользователем режиму. Формы не отправляют и не сохраняют сведения. Видео предоставлено пользователем; сохранено без удаления водяных знаков, затемнено средствами CSS. При reduced-motion/data-saver используется постер с возможностью ручного запуска.
