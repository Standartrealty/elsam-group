# ELSAM Group

Отдельный сайт строительной компании «Эльсам», созданный по материалам https://elsamgroup.ru/.

## Запуск

Node.js 22+: `npm run dev` (порт 4195), `npm run check`, `npm run build`. Результат сборки — `dist/`, Vercel использует `vercel.json`.

## Состав

Первый экран с предоставленным видео и затемнением; компания и показатели; 5 проектов с галереями и документами; 61 планировка с фильтрами и увеличением; подбор квартиры; условия покупки; завершённые объекты; расположение; коммерция, паркинг и кладовые; отделка; консультация; отзывы 2ГИС; FAQ; контакты. На мобильных — панель из пяти действий.

Формы демонстрационные: нет API отправки, сохранения или CRM. WhatsApp, Telegram, карты и личный кабинет открывают официальные внешние сервисы.

## Архив первоисточника

Полный локальный архив находится в `source-content/`: 19 сохранённых страниц с оригинальным HTML и извлечённым текстом, 467 сохранённых ресурсов. `catalog.json` содержит соответствие URL, файлов, статуса и ошибок. Ссылки на внешние документы сохранены; сами внешние PDF в архив не включены. Архив отражает доступный на момент сбора контент, а не гарантирует наличие скрытых/удалённых материалов.

Исходные тяжёлые ресурсы остаются в локальном архиве. Репозиторий содержит оптимизированные материалы для сайта, текстовые снимки, каталог и список использованных ресурсов. `collect_source.py` позволяет повторить сбор. Пользовательское видео используется как видеоиллюстрация, не как подтверждённая съёмка объектов компании.

## Проверка контента

См. `VERIFICATION.md`. Противоречия исходника зафиксированы отдельно. Наличие и цены не выдумывались. Отзывы — короткие выдержки с прямой ссылкой на 2ГИС. Подтверждённых отзывов Яндекс не найдено.
